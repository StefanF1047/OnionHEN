# Security

Do not report errors to the official OnionHEN project using this modified version of OnionHEN

OnionHEN is unofficial PS5 homebrew. There is no warranty.

If OnionHEN crashes, hangs, or a setting is wrong, open a
[Bug report](https://github.com/aydencharles/onionHEN/issues/new?template=bug_report.yml).
Include firmware, version, how it was loaded, and logs from
`/data/OnionHEN/`.

To keep a report private, use this repository's Security tab.
